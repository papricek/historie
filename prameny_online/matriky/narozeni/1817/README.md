# Jan Ros / Roš v N11, 1817

Na [snímku 94 matriky narozených Pošná 1797–1843, knihy 6620](https://digi.ceskearchivy.cz/DA?doctree=1nrpI&menu=3&id=6620&page=94), je u domu `Zahrádka N11` zapsán **Jan Ros / Roš**, narozený 14. června a pokřtěný 15. června 1817. Historický tvar příjmení se podobá `Ros` či `Roß`; česká podoba Roš je pracovní normalizace.

## Rodiče

- Otec **Jakub Ros / Roš** je v zápisu výslovně označen jako **`panský ovčák na dvoře Zahrádeckém`**. Formulace přímo dokládá zaměstnance zahrádeckého dvora a je silnější než pouhá adresa dítěte.
- Matka se bezpečně jmenovala **Alžběta**. Zápis obsahuje také její rodový původ, ale překryté tvary za slovem `rozená` zatím nedovolují spolehlivě vytvořit příjmení.

## Oprava pozdějšího přípisu

Řádek pod zápisem začíná latinsky **`Vidi litteras baptismales die 25. Januarii 1842`** — tedy sdělením, že dne 25. ledna 1842 byl viděn či ověřen křestní list. Nejde o zápis úmrtí a rok není 1822. Dřívější pracovní údaj o Janově úmrtí byl proto z evidence odstraněn.

Veřejný jmenný index SOA Třeboň přinesl pro výraz `Ros` v letech 1817–1842 jen nesouvisející táborský rejstříkový záznam; příjmení rodiny tedy nezávisle nepotvrdil.
