# Václav Vojtěch v N11, 1836

Rodný zápis na [snímku 112 knihy 6620](https://digi.ceskearchivy.cz/DA?doctree=1nrpI&menu=3&id=6620&page=112) uvádí 19. 10. 1836 narození i křest Václava Vojtěcha v domě `Zahrádka N11`.

Uložené obrazy:

- [výřez celého řádku](zaznam_vaclav_vojtech_n11_snim112.jpg),
- [zvětšený detail rodičovských sloupců](detail_rodice_vaclav_vojtech_n11_snim112.png).

Otec je Václav. Po zvětšení začíná jeho příjmení zřetelným `L` a celý tvar odpovídá spíše **`Löbl`** než dřívějšímu pracovnímu čtení `Bílý`; jistota je střední, protože nezávislý zápis téže osoby zatím chybí. Matka se jmenovala Anna. Další údaje o původu a rodičích obou dospělých zůstávají k úplnému paleografickému přepisu.
