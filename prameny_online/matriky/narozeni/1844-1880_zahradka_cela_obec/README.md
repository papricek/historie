# Zahrádka — narození 1844–1880, celá obec

Pramen: [SOA Třeboň, římskokatolická farnost Pošná, kniha narozených
6621](https://digi.ceskearchivy.cz/6621).

Zahrádecký oddíl začíná na snímku 309 a končí posledními rodnými zápisy na
snímku 362. Snímky 360–362 obsahují vedle Zahrádky také Zlátenku; snímek 363 už
je abecední rejstřík. Celý personální průchod tedy zahrnuje snímky **309–362** a
roky **1844–1880**. Badatelské označení `snímek 309` zachovává číslování použité
v dosavadní evidenci; jeho přímý veřejný obraz má adresu
[`/6621/308`](https://digi.ceskearchivy.cz/6621/308).

Ukládají se celé snímky, nikoli soustava trvalých výřezů. Nejasná příjmení se
nedoplňují jen podle známých místních rodů. Datum je uváděno jako narození /
křest; pokud druhý den v matrice chybí, je to výslovně poznamenáno.
